## 🧱 How I work

- **Measure first.** If it has no SLO, it has no priority.
- **Automate the toil.** Anything done twice by hand becomes code.
- **Everything as code.** Infra, policy, dashboards and alerts live in Git and go through review.
- **Secure by default.** Scans and policy checks run in the pipeline, not after release.
- **Blameless by default.** Postmortems fix systems, not people.
- **Cost is a reliability signal.** Efficient systems are easier to keep up.
